# 🎵 Mood Music Player

A modern Mood-Based Music Player built using React.js and Vite that recommends songs based on user mood and preferred language.

---

## 🚀 Live Demo

https://mood-music-player-liart.vercel.app

---

## ✨ Features

- 🎧 Mood-based song recommendations
- 🌍 Multi-language support
- 🎵 Spotify embedded player
- 📱 Responsive modern UI
- ⚡ Fast performance with Vite
- 🎨 Attractive gradient design

---

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- CSS
- Spotify Embed
